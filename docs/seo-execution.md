## 页面分工

- 首页承接“网盘搜索、网盘搜索引擎、网盘资源搜索、好搜库”等核心需求。
- 平台页承接“平台名 + 搜索、资源、入口、内容类型”等组合。
- 分类页承接“内容类型 + 网盘、资源、搜索”等组合。
- 专题页承接“年份、版本、科目、格式、清晰度、字幕”等具体条件。
- 组合搜索页承接“平台名 + 内容类型 + 年份、版本或格式”等明确长尾需求。
- 影视作品页承接“具体片名 + 网盘、平台、年份、清晰度、字幕或集数”等实体搜索需求。
- 指南页回答用户在搜索模式、文件名、格式和打开结果时遇到的实际问题。
- 搜索参数页保持 `noindex,follow`，不把用户输入自动生成可索引页面。

## 文案标准

- 开头直接说明这个页面能解决什么问题，不写空泛背景。
- 平台页写平台差异，分类页写内容差异，两者不互相套模板。
- 每段只处理一个判断：搜什么、怎么缩小、打开后看什么。
- 不使用“致力于、一站式、海量资源、全网最全、高效便捷、轻松找到、赋能”等生成式文案常见表达。
- 不承诺永久有效、全部可用或一定有结果。
- 影视写年份、版本、字幕和集数；资料写年份、科目和地区；软件写版本、系统和架构；图书写作者、译者和版次。
- 首屏搜索示例每页保留 4-5 条；组合页的扩展长尾词按搜索动作分组折叠，保持正文结构和浏览效率，不生成只有关键词列表的空页面。

## 技术规则

- 每个索引页必须有唯一标题、描述、canonical 和不少于两个正文小节。
- 平台、分类和专题页使用 `CollectionPage`；指南使用 `Article`；网站说明使用 `WebPage`。
- 首页搜索结果参数保持 canonical 指向首页，同时输出 `noindex,follow`。
- 页面中的搜索动作使用按钮跳转，不向爬虫暴露数千个 `/?q=` 查询链接。
- sitemap 只收录通过完整度检查的页面，并写入实际内容更新时间。
- API、测试页和错误页不得进入索引。
- 站点验证通过以下运行时变量注入，不把验证码写死到仓库：
  - `NUXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
  - `NUXT_PUBLIC_BING_SITE_VERIFICATION`

## 发布验收

- `pnpm test`：全部单元测试通过。
- `pnpm build`：Cloudflare Workers 构建成功。
- 抽查首页、平台页、分类页、专题页和指南页的 SSR HTML。
- 检查 title、description、canonical、robots 和 JSON-LD。
- 检查 sitemap 中 URL 数量、状态码、域名和 lastmod。
- 主站部署不再全量重复提交 sitemap。每日巡检只向 IndexNow 提交新增页、`lastmod` 变化页或上次失败的页面，避免部署频繁时触发 429 限流。
- `pnpm seo:submit` 只保留为人工应急命令，不作为默认部署步骤。
- 每周记录收录、展示词、点击率、平均排名、404 与抓取异常，按真实查询扩写页面，不批量生成空页。

## 自动增长闭环

### 每次访问与站内转化

- 首次进入时按会话记录入口页面、来源类型、来源站点简称和 UTM 活动。
- 只保存按天聚合的数据，不保存 IP、完整来源网址，也不建立跨会话用户档案。
- 搜索完成和结果打开会归到同一入口维度，用于判断页面带来的真实使用，而不是只看访问量。
- `/api/seo/report?days=28` 返回最近周期、近 7 天与前 7 天对比、入口页、来源、转化和技术巡检结果。

### 每日 Cloudflare 巡检

`haosouku-resource-sync` 每天北京时间 10:43 自动执行：

1. 获取主站 sitemap。
2. 检查所有页面的状态码、标题、描述、canonical、robots、H1 和结构化数据。
3. 检测重复标题和重复描述。
4. 将页面明细和当日汇总写入 D1。
5. 只向 IndexNow 提交新增、`lastmod` 变化或上次提交未成功的页面。

手动触发使用资源同步 Worker 的 `POST /seo/audit`，并携带 `SYNC_TOKEN` 或独立的 `SEO_AUDIT_TOKEN`。

### 自动内容发现与合规推广

- `/feed.xml` 提供 Atom 内容发现入口。
- `/opensearch.xml` 提供浏览器搜索描述。
- `pnpm seo:keywords` 从 Bing、360 和百度的公开搜索建议中更新长尾机会，按多来源重复度排序，并过滤登录、破解、会员、解析、下载器等不符合本站能力的词。Google 建议接口可用时可通过 `SEO_GOOGLE_SUGGESTIONS=1` 加入研究。
- 当前研究覆盖 84 个种子和 1,397 条过滤后建议词；数量只表示公开建议词条目，不代表搜索量、排名或收录。
- `pnpm seo:promotion-kit` 根据线上全部索引页生成知乎、微信和小红书 UTM 链接包，保存到 `outputs/seo/`。
- 推广素材只应发布到真正相关的文章、问答或社群。禁止批量刷帖、购买垃圾外链、伪造点击和承诺资源永久有效。

## 效果反馈口径

每周固定比较最近 7 天与前 7 天：

- 自然搜索入口数及环比；
- 自然搜索占全部入口的比例；
- 入口到站内搜索的转化率；
- 入口到结果打开的转化率；
- 有增长和下滑的入口页；
- sitemap 健康率、异常页面和增量提交状态。

Google Search Console 和 Bing Webmaster Tools 的展示量、平均排名与实际收录量，只有完成站点验证并授权后才能获取。平台生成数据前只报告站内归因、技术巡检和提交回执，不用 `site:` 搜索数量代替官方数据。
